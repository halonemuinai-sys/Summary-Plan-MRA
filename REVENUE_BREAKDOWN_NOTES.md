# Revenue Breakdown presentation

Open `/p/mra-altius-base-2025-2031/revenue`, or select **Revenue Breakdown Deck** in the admin sidebar. The route uses the selected scenario's saved Brand Revenue Matrix. Save admin edits before opening the presentation; reload an already-open presentation after saving changes.

## Data availability

- Workbook: `Group MRA Summary Plan 2025-2031_Altius_rev3.xlsx`, sheet `PL MRA Group+Holding (Combine)`.
- Consolidated segment history exists for 2018–2031. Complete brand rows 97–117 cover 2026–2031 only, so the four-panel presentation uses this common period.
- The screenshot is a design reference, not the numerical source. Its FY2022–2030 values differ from this workbook.
- Retail includes Bulgari, Omega, L'OREAL, Wiggle Wiggle, Atmos, Metrox, and new retail businesses. F&B includes Haagendazs, new F&B businesses, and Hard Rock Bali. Media contains Publisher.
- Atmos, Metrox, and Hard Rock Bali have explicit zero revenue throughout the initial 2026–2031 matrix. Broadcast has no separate brand data and is not plotted as a fabricated zero series.
- Heading rows and the stored TOTAL are excluded from sums. Full-rupiah values are preferred over rounded billion values. Missing brand-year values are not treated as zero; incomplete years are excluded. Unknown brands without a segment mapping stop chart rendering with a visible message.
